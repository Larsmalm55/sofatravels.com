# Sofatravels

A digital travel planning platform for discovering routes, hidden stories, and meaningful destinations before you travel.

## What it does
- Suggests travel routes and place-based experiences
- Highlights hidden stories and overlooked locations
- Helps travelers plan before arrival

## Features (planned)
- Route planner
- Story-based travel guides
- QR discovery system
- City and landscape micro-guides

## Tech Stack
- HTML/CSS/JavaScript (eller React hvis aktuelt)
- Netlify (deployment)
- Formspree (forms)
- Gumroad (digital products)

## Status
Early prototype / In development.
